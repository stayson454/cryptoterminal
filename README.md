# CryptoTerminal

Браузерный терминал для криптовалют на публичных данных Binance:
кластерный график (свечи, профиль, футпринт), тепловая карта Z-Score
стакана, карта глубины, 12 индикаторов, котировки Binance / Coinbase /
Deribit и страница «Маржа Binance».

Работает целиком в браузере: свечи, сделки и стакан берутся напрямую из
публичных REST и WebSocket Binance. Ключи и регистрация не нужны.

## Как открыть

Онлайн: страница GitHub Pages этого репозитория.

Локально:

```bash
python server.py
```

и открыть http://127.0.0.1:8765

## Займы, погашения и пул на странице «Маржа»

Без ключа страница показывает публичные ставки и лимиты займа по всем
маржинальным активам. Займы, погашения, пул, Z-оценки и события требуют
API-ключа Binance **только на чтение** и запущенного `server.py`
(на GitHub Pages сервер не работает — только локально или на своём VPS):

1. Создайте ключ Binance типа «Сгенерированный системой» (HMAC) с
   единственным правом «Enable Reading».
2. Рядом с `index.html` создайте `config.local.json`:
   ```json
   {"binance_api_key": "…", "binance_api_secret": "…"}
   ```
   Файл исключён из git и не раздаётся сервером.
3. `python server.py` — пул опрашивается раз в минуту, история пишется
   в `data/`.

## Важно

История стакана на Binance публично не отдаётся, поэтому Z-Score на
прошлых свечах восстановлен моделью и калибруется по реальным снимкам
стакана; реальные снимки копятся в IndexedDB браузера, пока терминал открыт.
Это инструмент для анализа, а не торговая рекомендация.
