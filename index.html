Как включить займы, погашения и пул

Binance отдаёт пул кросс-маржи только по API-ключу. Терминал выводит займы и погашения из изменений пула: пул уменьшился — взяли в долг, вырос — вернули.

  1. В Binance → Управление API создайте ключ с единственным правом «Enable Reading» (без торговли и вывода). Лучше ограничить его по IP.
  2. Рядом с index.html создайте файл config.local.json:
    {"binance_api_key": "…", "binance_api_secret": "…"}
    Файл исключён из git и не раздаётся сервером.
  3. Запустите python server.py и откройте http://127.0.0.1:8765.

Пул опрашивается раз в минуту, история пишется в папку data/ и переживает перезапуск. Суммы за 24 ч заполняются через сутки работы, Z-оценки — когда наберётся база.
